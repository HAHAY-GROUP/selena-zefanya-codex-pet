# Selena Zefanya

Selena Zefanya is a warm, calm, and witty animated companion for Codex. She brings a little personality to your workspace while you think, build, review, and wait for things to finish.

## What’s included

This package contains everything needed to install the pet:

- `pet.json` — Selena’s package information.
- `spritesheet.webp` — her animated artwork and expressions.

## Installation

Install the package through the Codex pet import flow, using this folder as the package source. Keep `pet.json` and `spritesheet.webp` together in the same folder.

If you are installing manually, select `pet.json` when Codex asks for a pet package. The spritesheet is referenced automatically through the package metadata.

## About Selena

Selena is designed to feel helpful without becoming distracting: thoughtful during focused work, expressive when something needs attention, and quietly present when the workspace is idle.

She is part of the HAHAY Group identity and is intended for personal and team Codex environments.

## Compatibility

This is a Codex animated pet package using the v2 sprite format. No additional dependencies or setup files are required.
